# 📮 郵差安裝說明（自動發送到 LINE 官方帳號、FB 粉專、IG）

「郵差」是一個放在 **Google Apps Script** 的免費小程式。它做四件事：

1. **保管鑰匙**：LINE、FB、IG 的鑰匙放在郵差那裡，不會出現在公開的網站程式裡。
2. **等時間到**：老師在網站「📤 本週發送」按「✅ 確認」後，郵差每 5 分鐘看一次，時間到（每週二 17:00）就發。
3. **暫存照片**：要發到 IG／FB 的照片，會**暫時**放在你的 Google 雲端硬碟，**發完就刪掉**。
4. **回報結果**：成功或失敗，網站上都看得到。失敗的部分可以按「重送」，成功的不會重複發。

> 🧒 比喻：網站是「寫信的老師」，郵差是「保管郵票、準時寄信的人」。老師把信和照片交給郵差，郵差 17:00 一到就寄出去，寄完把照片的影本丟掉。

| 發到哪裡 | 文字 | 照片 |
|---|---|---|
| 📱 LINE 官方帳號 | ✅ 自動（週會＋踏查兩個泡泡） | ✋ 老師用手機自己傳 |
| 📘 FB 粉專 | ✅ 自動 | ✅ 自動（可以選要不要附） |
| 📸 IG | ✅ 自動 | ✅ 自動（一定要有照片，最多 10 張） |

全部大約要 **50 分鐘**，分成 4 段：**A. 建立郵差 → B. LINE 鑰匙 → C. FB＋IG 鑰匙 → D. 安全地試用**。
請用**建立 Firebase 的同一個 Google 帳號**來做（照片會暫存在這個帳號的雲端硬碟）。

---

## A. 建立郵差（約 10 分鐘）

1. 打開 <https://script.google.com/> → 左上角「**新專案**」。
2. 左上角把「未命名的專案」改成「**踏查郵差**」。
3. 把編輯區裡原本的內容**全部刪掉**，貼上 [`postman.gs`](./postman.gs) 的**全部**內容 → 按 💾 儲存。
4. 左邊 ⚙️「**專案設定**」→ 拉到最下面「**指令碼屬性**」→「新增指令碼屬性」，一個一個加：

   | 屬性 | 要填什麼 | 現在就填？ |
   |---|---|---|
   | `SECRET` | 郵差密碼：自己打一串**至少 20 個字**的英文＋數字（例如亂打鍵盤），網站設定也要貼一樣的 | ✅ 現在 |
   | `DRY_RUN` | 填 `1`（測試模式：**什麼都不會真的發出去**） | ✅ 現在 |
   | `LINE_TOKEN` | B 段拿到的 LINE 鑰匙 | B 段 |
   | `LINE_TEST_USER_ID` | B 段拿到的「老師自己的 User ID」（試用時只發給老師自己） | B 段 |
   | `FB_PAGE_ID` | C 段拿到的粉專編號 | C 段 |
   | `FB_PAGE_TOKEN` | C 段拿到的粉專鑰匙（**IG 也用這一把**） | C 段 |

5. 回到「編輯器」(`< >` 圖示)，上方函式選單選「**安裝**」→ 按「▶ 執行」。
   - Google 會問權限：選你的帳號 → 如果出現「**Google 尚未驗證這個應用程式**」，按「**進階**」→「**前往踏查郵差（不安全）**」→「允許」。
   - 會問三種權限，都要允許：**連到外部網站**（LINE、FB、IG）、**Google 雲端硬碟**（暫存照片）、**在你不在的時候執行**（17:00 的鬧鐘）。
   - 🧒 這個警告是因為郵差是**你自己放的程式**，沒有給 Google 審查過，不是病毒。只要程式是從這裡複製的就可以。
   - 下方「執行記錄」出現「✅ 鬧鐘設定好了」就成功了。你的雲端硬碟會多一個資料夾「**踏查郵差暫存照片（發完會自動刪除）**」，**不要放其他東西進去**。
6. 右上角「**部署**」→「**新增部署作業**」→ 左邊齒輪選「**網頁應用程式**」：
   - 說明：踏查郵差
   - **執行身分：我**
   - **誰可以存取：所有人**（不用登入 Google 也能叫郵差。安全靠的是 `SECRET` 郵差密碼）
   - 按「部署」→ 複製「**網頁應用程式網址**」（最後是 `/exec`）。
7. 打開網站 →「⚙️ 設定」→「📮 自動發送（郵差）」：貼上網址和 `SECRET` → 按「**💾 儲存設定**」→ 按「**📮 檢查郵差**」。看到「✅ 郵差有回應，密碼正確」和「📁 雲端硬碟：✅」就成功了（LINE、FB、IG 還是 ❌ 沒關係，等 B、C 段做完）。

> ⚠️ 以後如果要**更新郵差的程式**：貼上新程式 → 儲存 → **再執行一次「安裝」**（新功能可能要新的權限）→「部署」→「管理部署作業」→ 鉛筆 ✏️ →「版本」選「**新版本**」→ 部署。這樣網址不會變。

## B. LINE 官方帳號的鑰匙（約 10 分鐘）

1. 打開 [LINE Official Account Manager](https://manager.line.biz/)，選你們的官方帳號。
2. 右上角「**設定**」→ 左邊「**Messaging API**」→「**啟用 Messaging API**」→ 選或建立一個「服務提供者（Provider）」，名字可以打學校名稱 → 確定。
   - ⚠️ 啟用之後，請到「**回應設定**」看一下聊天、自動回應是不是跟原本一樣。如果被改掉，改回原本的設定。
3. 打開 [LINE Developers](https://developers.line.biz/console/)，用同一個 LINE 帳號登入 → 點剛剛的服務提供者 → 點你們的官方帳號（頻道）。
4. 「**Messaging API**」分頁 → 拉到最下面「**Channel access token (long-lived)**」→「**Issue**」→ 複製那一長串 → 貼到郵差的 `LINE_TOKEN`。
5. 「**Basic settings**」分頁 → 拉到最下面「**Your user ID**」（U 開頭的一串）→ 複製 → 貼到郵差的 `LINE_TEST_USER_ID`。
   - 🧒 這是**你自己**的 LINE 編號。先填這個，郵差就只會把訊息發給你一個人，不會發給 100 多位家長。
   - 你自己的 LINE 要先**加官方帳號好友**，才收得到。

📊 **額度**：LINE 群發是「**一位好友收到一次＝1 則**」。100 多位好友、每週二送一次（週會＋踏查兩個泡泡算 1 次），一個月大約 **430～500 則**。在網站按「📮 檢查郵差」可以看到**這個月已經用了幾則**。

## C. FB 粉專＋IG 的鑰匙（約 20 分鐘，最複雜的一段）

> ⚠️ Meta（FB 和 IG 的公司）規定常常改。下面是我查到的做法，畫面的文字可能跟你看到的不一樣。卡住的時候截圖給我（**截圖前把鑰匙遮起來**）。

### C-1. 先確認 IG 帳號（在手機上做）

1. IG App → 右下角大頭貼 → 右上角 ☰ →「**帳號類型與工具**」→ 確認是「**專業帳號**」（商家或創作者）。如果還是「個人帳號」，按「切換為專業帳號」。
2. 把 IG **連結到 FB 粉專**：FB 粉專 →「設定」→「**已連結的帳號**」→ Instagram →「連結帳號」→ 登入你們的 IG。

### C-2. 拿鑰匙

1. 打開 [Meta for Developers](https://developers.facebook.com/apps/)，用**粉專管理員**的 FB 帳號登入 →「**建立應用程式**」。
   - 名稱：踏查郵差
   - 使用案例：選「**管理粉絲專頁上的所有內容**」（英文是 Manage everything on your Page）。如果有「**管理 Instagram 上的訊息和內容**」，也一起加。
   - 如果問要不要連結「企業管理平台／商家」，可以先略過。
2. 打開 [Graph API 測試工具](https://developers.facebook.com/tools/explorer/)：
   - 右邊「Meta 應用程式」選「**踏查郵差**」
   - 「使用者或粉絲專頁」選「**取得使用者存取權杖**」
   - 「權限」加這五個：
     - `pages_manage_posts`（FB 發文、上傳照片）
     - `pages_read_engagement`
     - `pages_show_list`
     - `instagram_basic`（找到你們的 IG）
     - `instagram_content_publish`（IG 發文）
   - 按「**Generate Access Token**」→ 登入 → **勾選你們的粉專和 IG** → 完成。
3. 這時拿到的鑰匙**一兩個小時就會過期**，要換成長效的：
   - 複製上面那串鑰匙 → 打開 [存取權杖偵錯工具](https://developers.facebook.com/tools/debug/accesstoken/) → 貼上 →「偵錯」→ 最下面按「**延長存取權杖**」→ 複製新的那串。
4. 回到 Graph API 測試工具 → 把新的那串貼到「存取權杖」欄 → 上面網址欄打 `me/accounts` →「提交」。
   - 結果裡找到你們的粉專，複製：
     - `id`（一串數字）→ 貼到郵差的 `FB_PAGE_ID`
     - `access_token`（很長的一串）→ 貼到郵差的 `FB_PAGE_TOKEN`
   - 可以把這把 `access_token` 再貼到偵錯工具看看，「到期」寫「**永不**」就對了。
   - 如果 `me/accounts` 是空的，可能粉專放在「企業管理平台」裡：回到第 2 步，權限多加一個 `business_management` 再做一次。
5. 到網站按「📮 檢查郵差」：看到「📘 FB：✅ 粉專名稱」和「📸 IG：✅ @你們的帳號」就好了。
6. 應用程式**不用送審、不用上線**：只有你自己（應用程式的管理員，也是粉專管理員）在用。
   - ⚠️ 這一點我**還不能 100% 確定**，Meta 可能要求你做「商家驗證」。如果「檢查郵差」是 ✅，但真的發文時出現權限錯誤，請截圖給我。
7. 以後**改了 FB 密碼**或**不再是粉專管理員**，鑰匙會失效。網站會顯示「鑰匙過期」，照第 2～4 步再拿一次就好。

### 📷 照片是怎麼送到 IG 的？

IG 規定：照片要放在「網路上抓得到的地方」，IG 會自己來抓。所以郵差在 17:00 會這樣做：

1. 從雲端硬碟拿出照片 → 上傳到你們的 FB 粉專，但**先不公開**。
2. 叫 IG 去抓這幾張照片 → IG 發成一篇貼文（2 張以上會變成可以左右滑的「輪播」）。
3. 如果 IG 抓不到，郵差會改成把雲端硬碟的照片暫時設成「知道連結的人可以看」，再叫 IG 抓一次。
4. 發完就刪掉：雲端硬碟的照片、FB 上不公開的照片都刪掉。（FB 貼文用到的照片不會刪，不然貼文的照片會不見。）

IG 只收**寬高比 4:5（直的）到 1.91:1（橫的）**的照片，所以網站會自動把太長、太寬的照片**從中間裁掉一點**。第 1 張照片決定整篇貼文的形狀。

## D. 安全地試用（一定要照順序）

| 步驟 | 郵差的設定 | 會發生什麼 |
|---|---|---|
| ① 假裝發送 | `DRY_RUN` = `1` | 按「確認」→ 時間到 → 網站顯示「✅ 已發送（測試模式）」，**其實什麼都沒發**，照片也會照樣刪掉 |
| ② LINE 真的發給自己 | 刪掉 `DRY_RUN`，保留 `LINE_TEST_USER_ID`；網站上**取消勾選 FB 和 IG** | **只有你自己**的 LINE 收到，看看格式對不對 |
| ③ 正式 | 刪掉 `LINE_TEST_USER_ID` | LINE 發給所有好友，FB 和 IG 也一起發 |

- 💡 **不想等到星期二 17:00 才試？** 到網站「⚙️ 設定」把「發送時間」改成**幾分鐘後**→ 儲存 → 到「📤 本週發送」按確認 → 等 5～10 分鐘 → 按「🔄 重新整理狀態」。**試完記得改回 17:00。**
- 💡 **FB 和 IG 沒有「只給自己看」的測試模式。** 第一次正式發的時候，請在旁邊看著；如果發錯了，可以到粉專或 IG App 裡把貼文刪掉。

## ❓ 常見問題

- **郵差沒有回應**：網址要用 `/exec` 結尾的那個；部署的「誰可以存取」要選「所有人」。
- **郵差密碼不對**：網站設定的密碼要跟 `SECRET` **一模一樣**（大小寫、空白都算）。
- **鬧鐘還沒設定**／**雲端硬碟 ❌**：到 Apps Script 選「安裝」→ 執行一次，權限都按允許。
- **IG：粉專還沒有連結 IG 專業帳號**：照 C-1 做；做完要**重新拿一次鑰匙**（C-2 的第 2～4 步）。
- **IG 抓不到照片**：郵差會自動換另一種方法再試一次。兩種都失敗的話，網站會顯示原因，可以按「重送失敗的部分」。
- **時間過了 6 小時才被郵差看到**：為了安全，郵差**不會**半夜突然發出去，會顯示「⌛ 沒有發送」，照片也會刪掉，請老師自己決定要不要重新排。
- **照片會留多久？** 從老師按「確認」到發完。發完馬上刪。按「取消」也馬上刪。沒發成功的，3 天後自動刪。萬一刪不掉，網站會提醒你到雲端硬碟手動刪。
- **免費嗎？** Google Apps Script 免費，照片只是暫存，不會用掉多少雲端硬碟空間。LINE 的費用照你們官方帳號原本的方案算。FB、IG 發文免費。
