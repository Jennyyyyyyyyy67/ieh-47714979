# 📮 郵差安裝說明（自動發送到 LINE 官方帳號和 FB 粉專）

「郵差」是一個放在 **Google Apps Script** 的免費小程式。它做三件事：

1. **保管鑰匙**：LINE 和 FB 的鑰匙放在郵差那裡，不會出現在公開的網站程式裡。
2. **等時間到**：老師在網站「📤 本週發送」按「✅ 確認」後，郵差每 5 分鐘看一次，時間到（每週二 17:00）就發。
3. **回報結果**：成功或失敗，網站上都看得到。失敗的部分可以按「重送」，成功的不會重複發。

> 🧒 比喻：網站是「寫信的老師」，郵差是「保管郵票、準時寄信的人」。老師把信交給郵差，郵差 17:00 一到就寄出去。

全部大約要 **40 分鐘**，分成 4 段：**A. 建立郵差 → B. LINE 鑰匙 → C. FB 鑰匙 → D. 安全地試用**。
建議用**建立 Firebase 的同一個 Google 帳號**來做。

---

## A. 建立郵差（約 10 分鐘）

1. 打開 <https://script.google.com/> → 左上角「**新專案**」。
2. 左上角把「未命名的專案」改成「**踏查郵差**」。
3. 把編輯區裡原本的內容**全部刪掉**，貼上 [`postman.gs`](./postman.gs) 的**全部**內容 → 按 💾 儲存。
4. 左邊 ⚙️「**專案設定**」→ 拉到最下面「**指令碼屬性**」→「新增指令碼屬性」，一個一個加：

   | 屬性 | 要填什麼 | 現在就填？ |
   |---|---|---|
   | `SECRET` | 郵差密碼：自己打一串**至少 20 個字**的英文＋數字（例如亂打鍵盤），網站設定也要貼一樣的 | ✅ 現在 |
   | `DRY_RUN` | 填 `1`（測試模式：**什麼都不會真的發出去**） | ✅ 現在 |
   | `LINE_TOKEN` | B 段拿到的 LINE 鑰匙 | B 段 |
   | `LINE_TEST_USER_ID` | B 段拿到的「老師自己的 User ID」（試用時只發給老師自己） | B 段 |
   | `FB_PAGE_ID` | C 段拿到的粉專編號 | C 段 |
   | `FB_PAGE_TOKEN` | C 段拿到的粉專鑰匙 | C 段 |

5. 回到「編輯器」(`< >` 圖示)，上方函式選單選「**安裝**」→ 按「▶ 執行」。
   - Google 會問權限：選你的帳號 → 如果出現「**Google 尚未驗證這個應用程式**」，按「**進階**」→「**前往踏查郵差（不安全）**」→「允許」。
   - 🧒 這個警告是因為郵差是**你自己寫的**，沒有給 Google 審查過，不是病毒。只要程式是從這裡複製的就可以。
   - 下方「執行記錄」出現「✅ 鬧鐘設定好了」就成功了。
6. 右上角「**部署**」→「**新增部署作業**」→ 左邊齒輪選「**網頁應用程式**」：
   - 說明：踏查郵差
   - **執行身分：我**
   - **誰可以存取：所有人**（不用登入 Google 也能叫郵差。安全靠的是 `SECRET` 郵差密碼）
   - 按「部署」→ 複製「**網頁應用程式網址**」（最後是 `/exec`）。
7. 打開網站 →「⚙️ 設定」→「📮 自動發送（郵差）」：貼上網址和 `SECRET` → 按「**💾 儲存設定**」→ 按「**📮 檢查郵差**」。看到「✅ 郵差有回應，密碼正確」就成功了（LINE、FB 還是 ❌ 沒關係，等 B、C 段做完）。

> ⚠️ 以後如果要**更新郵差的程式**：貼上新程式 → 儲存 →「部署」→「管理部署作業」→ 鉛筆 ✏️ →「版本」選「**新版本**」→ 部署。這樣網址不會變。

## B. LINE 官方帳號的鑰匙（約 10 分鐘）

1. 打開 [LINE Official Account Manager](https://manager.line.biz/)，選你們的官方帳號。
2. 右上角「**設定**」→ 左邊「**Messaging API**」→「**啟用 Messaging API**」→ 選或建立一個「服務提供者（Provider）」，名字可以打學校名稱 → 確定。
   - ⚠️ 啟用之後，請到「**回應設定**」看一下聊天、自動回應是不是跟原本一樣。如果被改掉，改回原本的設定。
3. 打開 [LINE Developers](https://developers.line.biz/console/)，用同一個 LINE 帳號登入 → 點剛剛的服務提供者 → 點你們的官方帳號（頻道）。
4. 「**Messaging API**」分頁 → 拉到最下面「**Channel access token (long-lived)**」→「**Issue**」→ 複製那一長串 → 貼到郵差的 `LINE_TOKEN`。
5. 「**Basic settings**」分頁 → 拉到最下面「**Your user ID**」（U 開頭的一串）→ 複製 → 貼到郵差的 `LINE_TEST_USER_ID`。
   - 🧒 這是**你自己**的 LINE 編號。先填這個，郵差就只會把訊息發給你一個人，不會發給 100 多位家長。
   - 你自己的 LINE 要先**加官方帳號好友**，才收得到。

📊 **額度**：LINE 群發是「**一位好友收到一次＝1 則**」。100 多位好友、每週二送一次（週會＋踏查兩個泡泡算 1 次），一個月大約 **430～500 則**。在網站按「📮 檢查郵差」可以看到**這個月已經用了幾則**。

## C. FB 粉專的鑰匙（約 15 分鐘，最複雜的一段）

> ⚠️ Meta（FB 的公司）規定常常改。下面是我查到的做法，畫面的文字可能跟你看到的不一樣。卡住的時候截圖給我。

1. 打開 [Meta for Developers](https://developers.facebook.com/apps/)，用**粉專管理員**的 FB 帳號登入 →「**建立應用程式**」。
   - 名稱：踏查郵差
   - 使用案例：選「**管理粉絲專頁上的所有內容**」（英文是 Manage everything on your Page）
   - 如果問要不要連結「企業管理平台／商家」，可以先略過。
2. 打開 [Graph API 測試工具](https://developers.facebook.com/tools/explorer/)：
   - 右邊「Meta 應用程式」選「**踏查郵差**」
   - 「使用者或粉絲專頁」選「**取得使用者存取權杖**」
   - 「權限」加這三個：`pages_manage_posts`、`pages_read_engagement`、`pages_show_list`
   - 按「**Generate Access Token**」→ 登入 → **勾選你們的粉專** → 完成。
3. 這時拿到的鑰匙**一兩個小時就會過期**，要換成長效的：
   - 複製上面那串鑰匙 → 打開 [存取權杖偵錯工具](https://developers.facebook.com/tools/debug/accesstoken/) → 貼上 →「偵錯」→ 最下面按「**延長存取權杖**」→ 複製新的那串。
4. 回到 Graph API 測試工具 → 把新的那串貼到「存取權杖」欄 → 上面網址欄打 `me/accounts` →「提交」。
   - 結果裡找到你們的粉專，複製：
     - `id`（一串數字）→ 貼到郵差的 `FB_PAGE_ID`
     - `access_token`（很長的一串）→ 貼到郵差的 `FB_PAGE_TOKEN`
   - 可以把這把 `access_token` 再貼到偵錯工具看看，「到期」寫「**永不**」就對了。
5. 應用程式**不用送審、不用上線**：只有你自己（應用程式的管理員，也是粉專管理員）在用。
   - ⚠️ 這一點我**還不能 100% 確定**，Meta 可能要求你做「商家驗證」。如果按「檢查郵差」FB 是 ✅，但真的發文時出現權限錯誤，請截圖給我。
6. 以後**改了 FB 密碼**或**不再是粉專管理員**，鑰匙會失效。網站會顯示「FB 鑰匙過期」，照第 2～4 步再拿一次就好。

## D. 安全地試用（一定要照順序）

| 步驟 | 郵差的設定 | 會發生什麼 |
|---|---|---|
| ① 假裝發送 | `DRY_RUN` = `1` | 按「確認」→ 時間到 → 網站顯示「✅ 已發送（測試模式）」，**其實什麼都沒發** |
| ② LINE 真的發給自己 | 刪掉 `DRY_RUN`，保留 `LINE_TEST_USER_ID`；網站上**取消勾選「發到 FB」** | **只有你自己**的 LINE 收到，看看格式對不對 |
| ③ 正式 | 刪掉 `LINE_TEST_USER_ID` | LINE 發給所有好友，FB 發到粉專 |

💡 **不想等到星期二 17:00 才試？** 到網站「⚙️ 設定」把「發送時間」改成**幾分鐘後**→ 儲存 → 到「📤 本週發送」按確認 → 等 5～10 分鐘 → 按「🔄 重新整理狀態」。**試完記得改回 17:00。**

## ❓ 常見問題

- **郵差沒有回應**：網址要用 `/exec` 結尾的那個；部署的「誰可以存取」要選「所有人」。
- **郵差密碼不對**：網站設定的密碼要跟 `SECRET` **一模一樣**（大小寫、空白都算）。
- **鬧鐘還沒設定**：到 Apps Script 選「安裝」→ 執行一次。
- **時間過了 6 小時才被郵差看到**：為了安全，郵差**不會**半夜突然發出去，會顯示「⌛ 沒有發送」，請老師自己決定要不要重新排。
- **照片和 IG**：郵差只發**文字**。照片請老師用手機傳到 LINE；IG 一定要照片，所以還是手動。
- **免費嗎？** Google Apps Script 免費。LINE 的費用照你們官方帳號原本的方案算。FB 發文免費。
